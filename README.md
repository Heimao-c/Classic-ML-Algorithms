# AI & Machine Learning Course Projects

本项目包含人工智能与机器学习课程的两个核心实战项目。通过对经典算法的底层实现（主要使用 NumPy）和模型调优，展示了对机器学习理论及应用的深度理解。

## 📂 项目结构

- `midterm_project/`: 工业预测性维护项目
- `final_project/`: 小麦种子数据集综合分析项目

---

## 🛠️ 项目一：工业预测性维护 (Midterm)

**目标**：基于 AI4I 2020 预测性维护数据集，预测机器是否会发生故障。

### 核心内容
* **实现算法**：线性回归 (Linear Regression)、感知机 (Perceptron)、逻辑回归 (Logistic Regression) 以及多层感知机 (MLP)。
* **数据预处理**：针对正负样本极度不平衡问题（339 正样本 vs 9661 负样本），采用了 **4% 负采样策略** 以平衡数据集。
* **优化技术**：为解决感知机训练时的剧烈波动问题，引入了 **L2 正则化** 增强模型稳定性。
* **实验结论**：在四个模型中，MLP 展示了最佳的收敛性能和预测效果。

---

## 🌾 项目二：小麦种子数据集综合分析 (Final)

**目标**：利用多种无监督与有监督学习技术对小麦种子进行聚类、降维及多类/二类分类任务。

### 核心内容
* **聚类分析**：实现并对比了 **K-Means++** 与 **Soft K-Means** 算法。
* **降维技术**：对比了线性的 **PCA** 与深层 **非线性自编码器 (Nonlinear Autoencoder)**。研究发现非线性自编码器在保留复杂数据模式方面表现更优。
* **分类任务**：
    * **多分类**：使用 MLP 进行三分类任务。
    * **二分类**：对比了 MLP、**线性 SVM**、**高斯核 SVM** 以及 **AdaBoost**。
* **实验结论**：高斯核 SVM 能够提供优越的非线性决策边界，而 AdaBoost 展示了极佳的集成鲁棒性。
